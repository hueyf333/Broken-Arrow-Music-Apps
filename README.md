# Broken Arrow Tab & Score Studio

A professional music notation and tablature editor built with JUCE framework, inspired by Guitar Pro.

## Features

- 🎸 Guitar tablature and standard notation
- 🎵 Multi-track score editing
- ⏯️ MIDI playback with metronome
- 💾 Save/load projects (JSON format)
- 📤 Export to MIDI and MusicXML
- ↩️ Full undo/redo support
- 🎨 Modern dark UI theme

## Build Instructions

See [README_BUILD.md](README_BUILD.md) for detailed build instructions.

### Quick Start

1. Install JUCE 7.0.9+ and Visual Studio 2022/2026
2. Open `BrokenArrowTabStudio.jucer` in Projucer
3. Set JUCE module path in Projucer Global Paths
4. Save and open in IDE
5. Build and run

## Requirements

- JUCE Framework 7.0.9 or later
- Visual Studio 2022 or 2026
- Windows x64
- C++20 compiler support
